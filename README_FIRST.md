# Natalia Borrego website starter — Page 1: Home

This is a plain static HTML/CSS site designed for GitHub Pages.

## Files

- `index.html` — homepage
- `assets/css/style.css` — all styling
- `assets/images/` — placeholder images

## Easiest way to replace a photo

1. Prepare your new photo as JPG.
2. Give it the SAME filename as the placeholder you want to replace.
3. In GitHub, open `assets/images/`.
4. Delete the old image.
5. Upload the new image with the same filename.
6. Commit the change.

You do NOT need to edit any HTML if the filename stays the same.

## GitHub Pages

Use this site in a repository named:

`YOUR-GITHUB-USERNAME.github.io`

The homepage is automatically loaded from `index.html`.

Do not add a custom domain until the basic GitHub Pages version is working.
